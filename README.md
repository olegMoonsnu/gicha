# Excel Column Parser

Консольная программа на Java 17 для чтения пар атрибутов из Excel-файла `.xlsx`. Программа печатает выражение для `Map<String, List<String>>`, которое можно скопировать из консоли и вставить после знака `=`.

## Запуск

Достаточно JDK 17 или новее. Запустите эту команду из папки проекта.

```bash
java -Dfile.encoding=UTF-8 src/main/java/com/github/olegmoonsnu/excel/Main.java "input.xlsx"
```

Команда компилирует и запускает исходник средствами JDK. Доступ к интернету и Maven для этого запуска не нужны. Можно передать полный путь к Excel-файлу. При запуске без аргументов используется путь из настройки `EXCEL_FILE`.

Если Maven доступен, можно собрать исполняемый JAR. Для такой сборки понадобятся плагины Maven.

```bash
mvn package
java -jar target/excel-column-parser.jar "input.xlsx"
```

Старый файл `.xls` перед запуском сохраните в Excel как книгу `.xlsx`.

## Настройка

Все настройки находятся в начале [Main.java](src/main/java/com/github/olegmoonsnu/excel/Main.java).

| Настройка | По умолчанию | Что менять |
| --- | --- | --- |
| `EXCEL_FILE` | `"input.xlsx"` | Имя или путь к Excel-файлу для запуска без аргументов. |
| `SHEET_NUMBER` | `1` | Номер листа, начиная с 1. |
| `FIRST_DATA_ROW` | `2` | Номер первой строки с данными. Укажите `1`, если заголовка нет. |
| `KEY_COLUMN` | `"A"` | Буква столбца с ключами. |
| `VALUE_COLUMN` | `"B"` | Буква столбца со значениями. |
| `COLUMN_OFFSET` | `0` | Общий сдвиг. При `1` столбцы `A` и `B` сдвинутся в `B` и `C`. |
| `SPLIT_BY_COMMA` | `true` | Делить текст в столбце значений по запятым. |
| `SPLIT_BY_NEWLINE` | `true` | Делить текст в столбце значений по переносам, например после Alt+Enter. |
| `OUTPUT_FORMAT` | `MapFormat.JAVA` | Вывод для Java. Для Groovy используйте `MapFormat.GROOVY`. |

Ячейка с ключом читается целиком. При двух выключенных разделителях текст из ячейки со значениями тоже читается целиком. Программа убирает пробелы по краям ключей и значений, пропускает строки с пустыми ключами и собирает значения повторяющихся ключей в общий список. Порядок и повторы внутри списка сохраняются. Ключ без значений получает пустой список.

Программа читает сохранённые результаты формул. Числа берутся в сохранённом в книге виде, а формат из одних нулей, например `00000`, дополняет число слева. Если для атрибута важно сохранить представление даты, валюты или другого формата, храните значение в Excel как текст.

## Пример

При стандартных настройках этот фрагмент Excel даст два ключа.

| A | B |
| --- | --- |
| `A-100` | `B-1, B-2` |
| `A-100` | `B-3` |
| `A-200` | `B-4` |

Скопируйте всю строку и вставьте её после знака `=` в объявлении переменной.

```java
var valuesByKey = java.util.Map.ofEntries(
    java.util.Map.entry("A-100", java.util.List.of("B-1", "B-2", "B-3")),
    java.util.Map.entry("A-200", java.util.List.of("B-4"))
);
```

В Java полученная мапа и её списки доступны для чтения. Порядок обхода ключей в Java может отличаться от порядка строк в Excel.

Для скрипта Groovy, в том числе в Naumen SD, установите `OUTPUT_FORMAT = MapFormat.GROOVY`. Вставьте результат после знака `=`.

```groovy
def valuesByKey = ['A-100': ['B-1', 'B-2', 'B-3'], 'A-200': ['B-4']]
```
