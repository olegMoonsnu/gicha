# Excel Column Parser

Консольная программа на Java 17 для чтения одного столбца из `.xlsx` или `.xls`. Собирает значения в одну строку в формате JSON. Её можно скопировать из консоли целиком.

## Настройка

Откройте [Main.java](src/main/java/com/github/olegmoonsnu/excel/Main.java). Все настройки находятся в начале класса.

| Настройка | По умолчанию | Что менять |
| --- | --- | --- |
| `EXCEL_FILE` | `"input.xlsx"` | Имя или путь к Excel-файлу для запуска без аргументов. |
| `SHEET_NUMBER` | `1` | Порядковый номер листа, начиная с 1. |
| `FIRST_DATA_ROW` | `2` | Номер первой строки с данными. Укажите `1`, если заголовка нет. |
| `COLUMN` | `"B"` | Буква столбца, например `"D"` или `"AA"`. |
| `COLUMN_OFFSET` | `0` | Сдвиг от указанного столбца. Для `"B"` сдвиг `-1` даст `A`, а `1` даст `C`. |
| `SPLIT_BY_COMMA` | `true` | Делить текст внутри ячейки по запятым. |
| `SPLIT_BY_NEWLINE` | `true` | Делить текст внутри ячейки по переносам строки, например после Alt+Enter. |

Для разделения только по переносам установите `SPLIT_BY_COMMA = false` и `SPLIT_BY_NEWLINE = true`. Если оба переключателя равны `false`, программа берёт текст каждой ячейки целиком.

Значения идут в порядке строк и элементов внутри ячейки. Программа убирает пробелы по краям значений, пропускает пустые элементы и сохраняет повторы. Разделители применяются к текстовым ячейкам и текстовым результатам формул. Числа читаются с форматом ячейки и остаются одним элементом. Для формул берётся последний результат, сохранённый в книге.

## Запуск

Нужны JDK 17 или новее и Maven 3.6.3 или новее. Из папки проекта выполните:

```bash
mvn clean package
java -jar target/excel-column-parser.jar "путь/к/файлу.xlsx"
```

Можно положить `input.xlsx` рядом с `pom.xml` и запустить JAR без аргументов. После правки настроек в исходном коде снова выполните `mvn clean package`.

В IntelliJ IDEA откройте `pom.xml` как Maven-проект, выберите JDK 17 и запустите метод `Main.main()`. Если файл лежит в другом месте, укажите путь в поле **Program arguments** конфигурации запуска.

## Пример

| Ячейка | Содержимое |
| --- | --- |
| B1 | Коды |
| B2 | `A-100` |
| B3 | `A-101, A-102` |
| B4 | `A-103` и `A-104` на разных строках внутри ячейки |

Вывод при стандартных настройках:

```json
["A-100","A-101","A-102","A-103","A-104"]
```

Все элементы выводятся строками. Если данных нет, результатом будет `[]`.
