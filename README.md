# Excel Column Parser

Консольная программа на Java 17 для чтения одного столбца из Excel-файла `.xlsx`. Программа печатает выражение для массива `String[]`, которое можно скопировать из консоли и вставить после знака `=`.

## Запуск

Достаточно JDK 17 или новее. Запустите эту команду из папки проекта.

```bash
java -Dfile.encoding=UTF-8 src/main/java/com/github/olegmoonsnu/excel/Main.java "input.xlsx"
```

Команда компилирует и запускает исходник средствами JDK. Доступ к интернету и Maven для этого запуска не нужны. Можно передать полный путь к Excel-файлу. При запуске без аргументов используется путь из настройки `EXCEL_FILE`.

Если Maven доступен, можно собрать исполняемый JAR. Для такой сборки понадобятся плагины Maven.

```bash
mvn package
java -jar target/excel-column-parser.jar "input.xlsx"
```

Старый файл `.xls` перед запуском сохраните в Excel как книгу `.xlsx`.

## Настройка

Все настройки находятся в начале [Main.java](src/main/java/com/github/olegmoonsnu/excel/Main.java).

| Настройка | По умолчанию | Что менять |
| --- | --- | --- |
| `EXCEL_FILE` | `"input.xlsx"` | Имя или путь к Excel-файлу для запуска без аргументов. |
| `SHEET_NUMBER` | `1` | Номер листа, начиная с 1. |
| `FIRST_DATA_ROW` | `2` | Номер первой строки с данными. Укажите `1`, если заголовка нет. |
| `COLUMN` | `"B"` | Буква столбца, например `"D"` или `"AA"`. |
| `COLUMN_OFFSET` | `0` | Сдвиг от столбца. Для `"B"` сдвиг `-1` даст `A`, а `1` даст `C`. |
| `SPLIT_BY_COMMA` | `true` | Делить текст в ячейке по запятым. |
| `SPLIT_BY_NEWLINE` | `true` | Делить текст в ячейке по переносам, например после Alt+Enter. |
| `OUTPUT_FORMAT` | `ArrayFormat.JAVA` | Вывод для Java. Для Groovy используйте `ArrayFormat.GROOVY`. |

При двух выключенных разделителях содержимое каждой ячейки становится одним элементом. Программа убирает пробелы по краям значений, пропускает пустые элементы и сохраняет порядок и повторы. Разделители применяются к тексту. Программа читает сохранённые результаты формул и не пересчитывает их. Числа берутся в сохранённом в книге виде, а формат из одних нулей, например `00000`, дополняет число слева. Если для атрибута важно сохранить представление даты, валюты или другого формата, храните значение в Excel как текст.

## Пример

Пусть в `B2` стоит `A-100`, в `B3` — `A-101, A-102`, а в `B4` — `A-103` и `A-104` на разных строках внутри ячейки. При стандартных настройках получится такое выражение Java.

```java
new String[] {"A-100", "A-101", "A-102", "A-103", "A-104"}
```

Скопируйте всю строку и вставьте её после знака `=` в объявлении переменной.

```java
String[] values = new String[] {"A-100", "A-101", "A-102", "A-103", "A-104"};
```

Для скрипта Groovy, в том числе в Naumen SD, установите `OUTPUT_FORMAT = ArrayFormat.GROOVY`. Вставьте результат после знака `=`.

```groovy
def values = ['A-100', 'A-101', 'A-102', 'A-103', 'A-104'] as String[]
```
